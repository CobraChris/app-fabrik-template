Chat-Link-Öffner

Diese Seite erscheint nur, wenn Android den Link nicht automatisch an die installierte App übergeben hat.

Die Zuordnung von Website und Android-App muss überprüft werden.

Prüfe in Android: Einstellungen → Apps → Chat-Link-Öffner → Als Standard festlegen → Unterstützte Links öffnen.

Alternativ: Zieladresse im Browser öffnen.
